phrasal-verbs dropped A verb plus a particle, such as set up, back up, turn on, work out or free up. Many phrasal verbs are the plainest wording a reader knows: 'turn on' is clearer to most readers than 'enable'. A fixed list cannot tell a verb from a noun ('set up' and 'setup', 'log in' and 'login') or a particle from a preposition ('look up the value' and 'walk up the stairs'). The suggested replacement often swaps a plain word for a more formal one. The trial documents use 'back up', 'set up', 'turn on', 'work out' and 'free up'. In most cases the single-word replacement is not clearly plainer. The answer key labels these 'none'. Only if a part-of-speech tagger is added to the core and a trial shows at least 90% precision. owner (plan v5 minimalism review); never implemented, 2026-10-14
noun-cluster dropped A run of more than three nouns, for example 'webhook notification delivery retry backoff configuration'. Without part-of-speech tagging the rule cannot tell nouns from adjectives or verbs. It would flag product names, headings, table headers and API names. Keeping it quiet needs a long exemption list, which is maintenance the project does not want. The six trial documents contain one real noun cluster and many capitalised names, headings and identifiers that a heuristic would flag. Only with a part-of-speech tagger and a trial result of at least 90% precision. owner (plan v5 minimalism review); never implemented, 2026-10-14
ing-clause-after-comma dropped A participle clause after a comma, for example ', making it faster'. Participle clauses are often correct and clear. The harm they cause is small, and the sentence-length rule already catches the long sentences where they hurt. No planted issue in the answer key depends on this rule. If a trial shows a real comprehension problem that only this rule catches, at 90% precision. owner (plan v5 minimalism review); never implemented, 2026-10-14
one-term-per-concept dropped A document that uses more than one word of a synonym group (check, verify, confirm; start, launch, initiate; delete, remove; show, display), at the first use of each word. Below the 90% precision gate. Most findings were delete and remove used for arguably different actions (delete a file locally, remove it from the bucket), which a word list cannot tell apart. The owner chose to drop it rather than make it opt-in, because an opt-in rule that rarely helps adds confusion.
